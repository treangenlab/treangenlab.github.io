microbiome analysis metagenomics

About the project

Microbial communities stay cooperative and resilient even though their genomes are in constant flux from gene duplication and horizontal gene transfer. This project develops computational tools for working out the rules that govern cooperation and resiliency in hot spring microbial mats from Yellowstone National Park, well-studied systems in which temperature, light and nutrients shape the diversity, abundance and evolution of microbial populations.

The project is a collaboration with Dr. Luay Nakhleh and Dr. Santiago Segarra at Rice and with the Carnegie Institution for Science.

Tools from this project

  • Emu: species-level profiling from full-length 16S nanopore reads
  • Bakdrive: finding the species that drive microbial community interactions
  • KOMB: K-core characterization of copy number variation in microbiomes
  • Rhea: reference-free structural variant detection in microbiomes
  • Parsnp: core-genome alignment for thousands of microbial genomes
  • SeqScreen: functional screening of pathogenic sequences
  • Seqwin: signature sequences in microbial genomes, for assay design

Listed tools are those whose papers are reported under this award by NSF. Source code for all lab tools is on the Code page.
