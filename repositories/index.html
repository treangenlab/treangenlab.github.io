    Gingr

    Interactive viewer for genome alignments and phylogenetic trees, part of the Harvest suite.

    • Scalable Algorithms and AI for Microbial Genomics
    • Pathogen Genomics and Wastewater Surveillance
    • Led by Todd Treangen and Brian Ondov
    gingr demo 
    $ parsnp -r examples/mers_virus/ref/England1.fna -d examples/mers_virus/genomes/*.fna -o examples-out
✓ done
$ gingr examples-out/parsnp.ggr
(Gingr opens the alignment, variants and tree in a window)
    Gingr: parsnp.ggr

    A drawing of the Gingr view, not a screen recording. It uses 16 of the MERS-CoV genomes from Parsnp's example data, with the tree on the left, one row per genome, and a coloured mark wherever a genome differs from the England1 reference.
