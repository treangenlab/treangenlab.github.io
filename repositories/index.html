    Run onsight yourself

    These run on your own computer. Nothing on this page runs the tool.

    1. Set up
      git clone https://github.com/treangenlab/onsight.git && cd onsight
      conda env create -f environment.yml && conda activate onsight
      make -j 8 && make install
    2. Run the example
      onsight --pore r10 --panel-dir example/panel -o example_out/ -t 4 example/reads.pod5
      cut -f 1,2,6,7 example_out/target_calls.tsv | grep -e entry -e neighbor_check
    3. Compare Your output should look like the replay above.

    The example reads and panel are in the repository.

    Drawn from a run of onsight on its example data (160 simulated reads, two-target panel): the signal traces are the reads' raw signal and the calls are the ones onsight wrote. The full 24-target panel covers the ESKAPE pathogens.

    Run Emu yourself

    These run on your own computer. Nothing on this page runs the tool.

    1. Set up
      conda config --add channels bioconda && conda config --add channels conda-forge
      conda install emu
      git clone https://github.com/treangenlab/emu.git && cd emu
      export EMU_DATABASE_DIR=$PWD/emu_database
    2. Run the example

      cut -f 1-3 results/full_length_rel-abundance.tsv | head -4
    3. Compare Your output should look like the replay above.

    The example reads and a default database are in the repository.

    Redrawn from the benchmark data behind the Emu paper (the per-iteration results in treangenlab/emu-benchmark): full-length 16S nanopore reads from the ZymoBIOMICS mock community. Each expectation-maximization iteration moves the estimates toward the ground truth; false positive species drop from 43 to 6 and L1 error from 0.254 to 0.034.
