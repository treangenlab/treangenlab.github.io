## About the project
This project, supported by the Defense Threat Reduction Agency, develops methods for detecting and characterizing microbial pathogens in the field, where computing power, connectivity and time are limited. The Treangen lab works on analysis that can keep pace with a portable sequencer and report what is in a sample while the run is still in progress.

## Tools from this project
- [SeqScreen](/projects/seqscreen/) (SeqScreen-Nano, for streaming, in-field characterization of microbial pathogens)
- [PlasmidScreen](/projects/plasmidscreen/): fast detection of engineered DNA in sequencing reads

Source code for all lab tools is on the [Code](/repositories/) page.
